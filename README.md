# 🧠 6. KONSEP PEMROGRAMAN YANG DIGUNAKAN

## 6.1 Variabel

Variabel digunakan untuk menyimpan data yang digunakan selama
program berjalan.

Contoh:

```python
nama = input("Masukkan nama: ")
```

---

## 6.2 Input

Input digunakan untuk menerima data dari pengguna.

Contoh:

```python
nama = input("Masukkan nama: ")
```

---

## 6.3 Output

Output digunakan untuk menampilkan informasi kepada pengguna.

Contoh:

```python
print("Data berhasil ditambahkan!")
```

---

## 6.4 Conditional Statement

Conditional digunakan untuk menentukan tindakan berdasarkan kondisi.

Contoh:

```python
if pilihan == "1":
    print("Tambah data")

elif pilihan == "2":
    print("Tampilkan data")

else:
    print("Pilihan tidak valid")
```

---

## 6.5 Perulangan

Perulangan digunakan untuk menjalankan suatu proses secara berulang.

Contoh:

```python
while True:
    print("Menu Program")
```

---

## 6.6 List / Tuple / Dictionary

Struktur data digunakan untuk menyimpan data dalam program.

Contoh:

```python
data = []
```

# 💻 9. SOURCE CODE

Source code utama terdapat pada:

👉 [`main.py`](main.py)

```python
# ==========================================
# NAMA PROGRAM : [Nama Program]
# NAMA         : [Nama Kamu]
# NIM          : [NIM]
# KELAS        : [Kelas]
# ==========================================

data = []

while True:

    print("\n================================")
    print("       [NAMA PROGRAM]")
    print("================================")
    print("1. Tambah Data")
    print("2. Tampilkan Data")
    print("3. Ubah Data")
    print("4. Hapus Data")
    print("5. Keluar")
    print("================================")

    pilihan = input("Pilih menu: ")

    if pilihan == "1":

        print("\n--- TAMBAH DATA ---")

        # Masukkan proses tambah data di sini

    elif pilihan == "2":

        print("\n--- TAMPILKAN DATA ---")

        # Masukkan proses tampilkan data di sini

    elif pilihan == "3":

        print("\n--- UBAH DATA ---")

        # Masukkan proses ubah data di sini

    elif pilihan == "4":

        print("\n--- HAPUS DATA ---")

        # Masukkan proses hapus data di sini

    elif pilihan == "5":

        print("\nProgram selesai.")
        break

    else:

        print("\nPilihan tidak valid!")
        print("Silakan pilih menu yang tersedia.")
```
